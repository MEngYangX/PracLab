# 安装部署

PracLab 由两层独立组件构成，可按需部署：

- **Layer 1（必需）**：`PracLab.dll` — CounterStrikeSharp C# 插件，提供全部命令与 UI。
- **Layer 2（可选）**：`PracLabReplayEngine.dll/.so` — Metamod C++ 插件，提供帧级移动录制/回放。未部署时仅 `.record/.replay` 系列命令不可用，其他功能不受影响。

> 构建产物可从 Release 下载，或参考[开发者文档](开发者.md)自行编译。

## 1. 前置依赖

| 依赖                                                                   |
| ---------------------------------------------------------------------- |
| CS2 服务器                                                             |
| [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp) |
| [Metamod:Source](https://www.sourcemm.net/)                            |

## 2. 部署 Metamod:Source 与 CounterStrikeSharp

PracLab 的两层组件分别依赖这两个框架：Layer 2（C++ 引擎插件）由 [Metamod:Source](https://www.sourcemm.net/) 加载，Layer 1（C# 插件）由 [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp) 运行。若服务器尚未安装，请先按官方指引完成部署：

- [CounterStrikeSharp 安装指南](https://docs.cssharp.dev/docs/guides/getting-started.html)

部署完成后，在服务器控制台执行 `meta list`，输出中应能看到 CounterStrikeSharp。

## 3. 部署 Layer 1 到 CS2 服务器

假设 CS2 服务器根目录为 `<CS2>`：

### 3.1 复制插件文件

```
<CS2>/game/csgo/addons/counterstrikesharp/plugins/PracLab/
├── PracLab.dll
└── lang/
    ├── zh-CN.json
    └── en.json
```

### 3.2 复制配置文件

```
<CS2>/game/csgo/cfg/PracLab/
├── config.cfg                 # 插件配置
├── prac.cfg                   # 练习模式配置
└── dryrun.cfg                 # 竞技模式配置
```

仓库内 `cfg/PracLab/` 目录已提供默认配置，直接整体复制即可。

### 3.3 启动服务器

启动后在控制台应看到：

```
[PracLab] Load: executing...
[PracLab] HH:mm:ss Core default language: zh-CN, plugin enabled: True (hotReload: False)
[PracLab] HH:mm:ss Core registered 9 map change commands, route table has XX keys
```

玩家在聊天栏输入 `.prac` 即可开启练习模式。

## 4. 部署 Layer 2 到 CS2 服务器

### 4.1 下载 Release 包并解压

从 [GitHub Releases](https://github.com/MEngYangX/PracLab/releases/latest) 下载 `PracLabReplayEngine.zip`，解压到 `<CS2>/game/csgo/`（压缩包内已含 `addons/` 目录结构）：

```
<CS2>/game/csgo/addons/PracLabReplayEngine/
├── gamedata.json                               # 签名扫描配置
└── bin/
    ├── win64/PracLabReplayEngine.dll           # Windows
    └── linuxsteamrt64/PracLabReplayEngine.so   # Linux
<CS2>/game/csgo/addons/metamod/
├── PracLabReplayEngine.vdf                     # Windows
└── PracLabReplayEngine.linux.vdf               # Linux
```

### 4.2 按平台清理 VDF

压缩包内同时包含两个平台的 VDF，而 Metamod 会加载 `addons/metamod/` 下所有 `*.vdf`，错误的 VDF 会导致加载报错，请删除当前平台不适用的一份：

- **Windows**：保留 `PracLabReplayEngine.vdf`，删除 `PracLabReplayEngine.linux.vdf`
- **Linux**：保留 `PracLabReplayEngine.linux.vdf`，删除 `PracLabReplayEngine.vdf`

### 4.3 验证

启动服务器，控制台应出现：

```
[PracLab] HH:mm:ss Replay engine detected: PracLabReplayEngine loaded
```

或在 PracLab 控制台执行 `.currentrecord`，若提示「回放引擎未加载」则说明 Layer 2 未正确部署。

## 5. 练习 HUD 资源（可选）

游戏内 HUD 面板（`.strafe` / `.shot` / `.sync`）需要客户端加载 VPK 资源 `prac_hud.vpk`（`.recoil` 压枪轨迹为世界空间绘制，不依赖该资源）。该资源源码位于仓库 [`hud/`](../../hud/) 目录，构建方式见[开发者文档](开发者.md)。

**未安装该资源时插件侧功能不受影响**：判定与统计仍在服务器侧正常工作（命令可开关、统计照常累计），玩家只是看不到 HUD 面板。

两种分发路径：

**① Steam 创意工坊（正式服推荐）**：将 `prac_hud.vpk` 发布到 Steam 创意工坊，玩家订阅后自动加载，无需手动操作。

**② 本地 overrides（本地开发/自建服）**：将 `prac_hud.vpk` 复制到客户端与服务器两侧的 `<CS2>/game/csgo/overrides/`，并在双方的 `gameinfo.gi` 中添加（置于 `Game csgo` 行之前）：

```
Game  csgo/overrides/prac_hud.vpk
```

添加后重启客户端与服务器生效。

## 6. 升级与回滚

| 操作         | 步骤                                                                                     |
| -----        | ------------------------------------------------------------------                       |
| 升级 Layer 1 | 覆盖 `PracLab.dll` 与 `lang/*.json` 等文件                                               |
| 升级 Layer 2 | 停止服务器 → 覆盖 `PracLabReplayEngine.dll/.so` → 启动服务器（Metamod 插件不支持热重载） |
| 回滚         | 替换为旧版本文件即可，配置文件向后兼容                                                   |
