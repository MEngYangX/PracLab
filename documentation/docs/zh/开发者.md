# 开发者

本页介绍如何从源码构建 PracLab 的两层组件，以及项目结构说明。部署产物请参考[安装部署](安装.md)。

| 依赖                                                                            | 版本     | 说明           |
| ------------------------------------------------------------------------------- | -------- | ----------     |
| [.NET SDK](https://dotnet.microsoft.com/download)                               | 10.0+    | 编译 Layer 1   |

## 2. 构建 Layer 1（PracLab C# 插件）

```powershell
# 在仓库根目录执行
dotnet build PracLab.csproj -c Release
```

产物路径：

```
bin/Release/net10.0/
├── PracLab.dll                # 主程序集
└── lang/
    ├── zh-CN.json             # 中文本地化（构建时自动复制）
    └── en.json                # 英文本地化
```

## 3. 构建 Layer 2（PracLabReplayEngine C++ 插件）

### 3.1 准备 SDK

将 HL2SDK CS2、Metamod 源码、protoc 解压到 `d:\PracLab\deps\`：

```
deps/
├── hl2sdk-cs2/
├── metamod-source/
├── protoc-3.21.8/
│   └── bin/protoc.exe
├── funchook/                 # funchook 源码（可选，否则 CMake 在线拉取）
└── nlohmann_json/            # nlohmann/json 源码（可选，否则 CMake 在线拉取）
```

### 3.2 配置 CMake

```powershell
cd d:\PracLab\replay-engine
.\configure.ps1
```

`configure.ps1` 会自动设置 MSVC 环境变量、清理旧缓存并用 Ninja 生成 Release 构建目录。脚本内硬编码了 MSVC 与 Windows SDK 路径，环境不同请按实际情况修改。

### 3.3 编译

```powershell
.\build.ps1
```

成功时输出：

```
=== SUCCESS ===
DLL: d:\PracLab\replay-engine\out\build\x64-Release\package\addons\PracLabReplayEngine\bin\win64\PracLabReplayEngine.dll
Size: XXX.XX KB
```

### 3.4 关键构建约束

以下源于引擎行为与项目规范：

- **protoc 版本**：为 3.21.x，CMakeLists.txt 会校验。
- **静态运行时**：Windows 使用 `/MT`（静态链接 CRT），保证插件可独立部署。
- **protoc 生成代码**：`.pb.h` 中类的 `final` 关键字会被自动移除，以允许 `PlayerCommand` 继承 `CSGOUserCmdPB`。
- **gamedata.json**：包含引擎函数签名，CS2 更新后可能需要重新扫描签名。详见 [`replay-engine/configs/addons/PracLabReplayEngine/gamedata.json`](../../replay-engine/configs/addons/PracLabReplayEngine/gamedata.json)。

## 4. 构建 HUD VPK 资源

游戏内 HUD 面板由 [`hud/`](../../hud/) 目录下的 VXML/VCSS 源码经 `tools/build_hud_resources.ps1` 编译打包为 `dist/prac_hud.vpk`。

### 4.1 构建依赖

| 依赖                                                                                             | 说明                                       |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| [VPKEdit CLI](https://github.com/craftablescience/VPKEdit)（`vpkeditcli.exe`）                    | 打包 VPK；从 release 下载后放入 `tools/vpkedit/`（已 gitignore） |
| CS2 `resourcecompiler.exe`                                                                        | 需安装免费 DLC「Counter-Strike 2 Workshop Tools」的 CS2 客户端 |

### 4.2 构建命令

```powershell
# 校验源文件（不调用编译器）
.\tools\build_hud_resources.ps1 -Action Validate

# 完整构建（Validate + Compile + Pack），-Cs2Root 必须指向带 Workshop Tools 的 CS2 客户端安装
.\tools\build_hud_resources.ps1 -Action Build `
    -Cs2Root "D:\Steam\steamapps\common\Counter-Strike Global Offensive" `
    -ResourceCompiler "<客户端>\game\bin\win64\resourcecompiler.exe" `
    -VpkEditCli "<路径>\vpkeditcli.exe"
```

产物：`dist/prac_hud.vpk`（部署方式见[安装文档](安装.md)的「练习 HUD 资源」小节）。

> **产物入库约定**：`dist/prac_hud.vpk` 随仓库分发（gitignore 仅放行该文件），并经 CI 附带到 Release assets。修改 `hud/` 源文件后必须本地重新构建并提交新的 vpk——CI 无编译器，无法自动发现 vpk 与源码不一致（`validate-hud` job 只校验源文件协议）。

### 4.3 关键约束

- **`-Cs2Root` 必须用 CS2 客户端安装**：服务器目录缺少 modtools 模块，resourcecompiler 会 FATAL。
- **编译产物必须带 `_c` 后缀**：只有 `.vxml_c`/`.vcss_c` 可打包进运行时 VPK，禁止直接打包未编译源文件。
- **根面板不允许携带 `id` 属性**（CCSCustomHudLayout 编译约束）；面板显隐全部由子面板 hidden class 控制。
- **受限资源模型**：无 VJS/HTML/audio，仅 VXML/VCSS + dialog variable + CSS class 显隐；构建脚本会校验 VXML 元素白名单与 C# 侧（`Commands/PracticeHud/PracticeHudCommands.cs`）的协议一致性（面板 id、dialog variables）。
- 修改 VXML/VCSS 协议（面板 id、变量名）时须同步更新构建脚本的校验清单与 C# 侧常量。

## 6. 跨语言 ABI 契约

Layer 1（C#）与 Layer 2（C++）之间通过 P/Invoke 调用 `PRL_*` 系列 C 函数通信。头文件位于 [`replay-engine/include/praclab_replay.h`](../../replay-engine/include/praclab_replay.h)。

修改 ABI 时须同步更新两层代码：

| 修改类型            | Layer 1（C#）                                         | Layer 2（C++）                                           |
| ----------          | --------------------------------------------------    | ----------------------------------------------------     |
| 新增/修改结构体字段 | `Commands/Replay/ReplayCommands.cs` 中的 `[StructLayout]` 类 | `include/praclab_replay.h` + `src/exports.cpp`           |
| 新增导出函数        | `Commands/Replay/ReplayCommands.cs` 中的 `[DllImport]` 声明  | `include/praclab_replay.h` 声明 + `src/exports.cpp` 实现 |
| 字段顺序调整        | 必须同步                                              | 必须同步（影响内存布局）                                 |
