# 配置文件

PracLab 的配置文件全部位于服务器的 `<CS2>/game/csgo/cfg/PracLab/` 目录下，仓库 [`cfg/PracLab/`](../../cfg/PracLab/) 提供默认模板。修改后需重启插件或服务器生效。

## 1. `config.cfg` — 插件总开关

**路径**：`<CS2>/game/csgo/cfg/PracLab/config.cfg`
**格式**：每行一个 ConVar，`key value` 用空格分隔，`//` 开头为注释。

| ConVar                     | 类型   | 默认值  | 说明                                                                                                          |
| -------------------------- | ------ | ------- | ----------------------------------------------------------------------                                        |
| `praclab_enabled`          | bool   | `true`  | 插件总开关。`false` 时所有命令（含 `.prac`、`.map`、地图切换）均不响应，向发送者打印「practice 模式未启用」。 |
| `praclab_default_language` | string | `zh-CN` | 服务器默认语言代码。可选 `zh-CN` / `en`。                                                                     |

## 2. 录制文件目录

**路径**：`<CS2>/game/csgo/cfg/PracLab/recordings/`

`.record` 命令保存的 JSON 录制文件存放在此目录，文件名格式 `<Id>_<PlayerName>.json`。`.clearrecord <Id>` 与 `.clearrecordall` 会同步删除文件与内存条目。

**自动创建**：插件 `Load` 时调用 `EnsureRecordingsDir()` 确保目录存在，无需手动创建。

**地图切换清空**：`OnMapStart` 监听器会清空内存中的录制列表（`_recordings.Clear()`），但**不删除 JSON 文件**；如需保留跨地图录制，可在玩家切换地图前先用 `.currentrecord` 记录 Id。

## 3. 出生点方框地图配置

每张地图的方框 Z 偏移与序号 yaw 旋转角度硬编码在 [`Commands/SpawnMarkerCommands.cs`](../../Commands/SpawnMarkerCommands.cs) 中：

- `SpawnTextYawByMap`：每张地图每队序号文本的 yaw 旋转角度（度）
- `SpawnExtraZOffsetByMap`：每张地图的方框/文本额外 Z 抬高量

**当前配置**：

| 地图        | T yaw | CT yaw | 额外 Z 偏移 |
| ----------- | ----- | ------ | -------     |
| de\_cache   | 90    | 180    | 0           |
| de\_train   | -90   | 0      | 0           |
| de\_anubis  | 0     | 180    | 0           |
| de\_vertigo | 90    | 180    | 0           |
| de\_ancient | 0     | 180    | 16          |
| de\_nuke    | -90   | 90     | 0           |
| de\_mirage  | 90    | -90    | 0           |
| de\_inferno | -90   | 90     | 0           |

未配置的地图默认 yaw=0、Z 偏移=0。新增地图支持时需在此表中补充配置并重新编译。

## 4. `hud.cfg` — 练习 HUD 判定参数

**路径**：`<CS2>/game/csgo/cfg/PracLab/hud.cfg`
**格式**：每行一个 ConVar，`key value` 用空格分隔，`//` 开头为注释。

**tick 粒度**：所有时间阈值均以 tick 为粒度——64 tick 服务器 1 tick ≈ 15.6ms，128 tick ≈ 7.8ms。判定随服务器 tickrate 自动缩放，无需按毫秒换算。

| ConVar                            | 类型  | 默认值 | 说明                                                                                 |     |                                                  |
| -------------------------------   | ---   | ------ | -------------------------------------------------------------------------            |     |                                                  |
| `strafe_max_diff_ticks`           | int   | `8`    | 急停评估：同轴双键（A/D、W/S）切换差超过此 tick 数丢弃，不产生记录                   |     |                                                  |
| `strafe_perfect_ticks`            | int   | `0`    | 急停评估：\                                                                          | 差\ | ≤ 此 tick 数判「完美」（0 = 同 tick 内完成切换） |
| `strafe_success_ticks`            | int   | `1`    | 急停评估：\                                                                          | 差\ | ≤ 此 tick 数判「优秀」                           |
| `strafe_debounce_ticks`           | int   | `4`    | 急停评估：防抖——两次记录最小间隔 tick 数，防止一次切换重复计入                       |     |                                                  |
| `strafe_history_limit`            | int   | `50`   | 急停评估：记录历史上限（用于统计平均差/成功率/标准差/趋势）                          |     |                                                  |
| `shot_history_limit`              | int   | `20`   | 开枪稳定：采样历史上限                                                               |     |                                                  |
| `shot_grace_ticks`                | int   | `12`   | 开枪稳定：移动键启动宽限——刚按下移动键的短时间内不判跑打                             |     |                                                  |
| `shot_crouch_release_grace_ticks` | int   | `3`    | 开枪稳定：下蹲释放宽限——松开蹲键后短时间内仍按蹲射精度判定                           |     |                                                  |
| `shot_crouch_exit_ramp_ticks`     | int   | `6`    | 开枪稳定：下蹲退出坡道——松蹲后误差按坡道线性恢复                                     |     |                                                  |
| `shot_success_error_threshold`    | float | `0.35` | 开枪稳定：稳定判定误差阈值（speed_ratio 归一化误差 ≤ 此值判成功，0.05–1.0）          |     |                                                  |
| `shot_weapon_thresholds_enabled`  | bool  | `true` | 开枪稳定：是否启用内置武器精度阈值表（AWP/狙击等更低阈值；`false` 时统一用默认阈值） |     |                                                  |
| `shot_default_threshold`          | float | `250`  | 开枪稳定：未收录武器的默认精度阈值（units/s，speed_ratio = 实际水平速度 / 阈值）     |     |                                                  |
| `sync_history_limit`              | int   | `30`   | 空中同步：近期空中段记录上限（用于均值/最佳统计）                                    |     |                                                  |
| `recoil_reset_ticks`              | int   | `64`   | 弹道追踪：射击间隔超过此 tick 数重置开火序列                                         |     |                                                  |
| `recoil_max_shots_per_sequence`   | int   | `30`   | 弹道追踪：单个开火序列最大记录弹数（连发防溢出）                                     |     |                                                  |
| `recoil_beam_enabled`             | bool  | `true` | 弹道追踪：是否在世界空间绘制压枪鼠标轨迹折线                                         |     |                                                  |
| `recoil_trace_scale`              | float | `2.5`  | 弹道追踪：轨迹缩放（1 度视角变化映射的画板世界单位数）                               |     |                                                  |
| `recoil_trace_distance`           | float | `80`   | 弹道追踪：轨迹画板与玩家眼位的距离（世界单位）                                       |     |                                                  |
| `recoil_trace_max_segments`       | int   | `256`  | 弹道追踪：单条轨迹最大 beam 段数（防溢出）                                           |     |                                                  |
| `hud_push_interval_ticks`         | int   | `2`    | HUD 面板文本推送间隔 tick 数（仅变化时差量推送）                                     |     |                                                  |

**内置武器精度阈值表**：`shot_weapon_thresholds_enabled` 开启时生效（units/s），未收录武器回退 `shot_default_threshold`：

| 武器            | 阈值 | 武器                   | 阈值 |
| --------------  | ---  | ---------------        | ---  |
| `weapon_awp`    | 100  | `weapon_galil`         | 180  |
| `weapon_ssg08`  | 120  | `weapon_famas`         | 180  |
| `weapon_g3sg1`  | 130  | `weapon_aug`           | 180  |
| `weapon_scar20` | 130  | `weapon_sg556`         | 180  |
| `weapon_ak47`   | 140  | `weapon_deagle`        | 220  |
| `weapon_m4a1`   | 150  | `weapon_m4a1_silencer` | 150  |

配置值超出合法范围时插件打印警告并回退默认值；`hud.cfg` 缺失时全部使用默认值。
