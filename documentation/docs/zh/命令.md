# 聊天栏命令

PracLab 通过拦截全局聊天（`say`）与队伍聊天（`say_team`）来识别玩家指令。所有命令均支持以下两种前缀形式，大小写不敏感：

| 前缀 | 示例    |
| ---  | ------- |
| `.`  | `.prac` |
| `!`  | `!prac` |

***

### 回放系统

| 命令                | 别名          | 功能                                                                                          |
| ------------------- | ------------- | -----------------------------------------------------------                                   |
| `.record`           | —             | 进入待录制状态，**玩家移动或按 F 键（检视键）开始录制**，再次按 F 或 `.stoprecord` 停止并保存 |
| `.stoprecord`       | —             | 停止录制并保存（与按 F 键等效）                                                               |
| `.replay [Id]`      | —             | 无参数：并行回放所有已停止的录制；指定 Id：仅回放该录制。自动创建同队 Bot 作为回放载体        |
| `.stopreplay`       | —             | 停止所有正在进行的回放并踢出对应 Bot                                                          |
| `.clearrecord <Id>` | —             | 删除指定 Id 的录制（同时删除 JSON 文件与列表条目）                                            |
| `.clearrecordall`   | —             | 清除所有录制                                                                                  |
| `.currentrecord`    | `.currentrec` | 在**服务器控制台**输出录制列表表格（ID / 名称 / 状态 / Bot）                                  |

> **二层架构**：回放系统由两部分组成——
>
> - **Layer 1（CSSharp C#）**：命令分发、UI 提示、录制文件 JSON 读写（`cfg/PracLab/recordings/`）。
> - **Layer 2（C++ Metamod 插件 `PracLabReplayEngine`）**：通过 Hook `ProcessMovement`、`CCSBot::Update`、`PlayerRunCommand` 等引擎函数实现帧级移动录制与回放。
>
> 跨语言 ABI 契约见 [`replay-engine/include/praclab_replay.h`](../../../replay-engine/include/praclab_replay.h)，修改字段顺序/类型须同步更新两层代码。
>
> **回放引擎未部署时**：所有 `.record/.replay/...` 命令会向玩家提示「回放引擎未加载，回放功能不可用」，但插件其他功能不受影响。

### 练习 HUD

| 命令        | 别名 | 功能                                           |
| ----------- | --   | ---------------------------------------------  |
| `.strafe`   | —    | 急停评估开关（HUD 面板显示判定与统计）         |
| `.shot`     | —    | 开枪稳定开关（HUD 面板显示速度误差与稳定占比） |
| `.sync`     | —    | 空中同步开关（HUD 面板显示 strafe 同步率）     |
| `.hudmove`  | —    | 移动 HUD 面板位置（编辑模式，见下文）          |
| `.hudreset` | —    | 清空当前玩家全部 HUD 统计                      |

> **使用说明**：四条命令均需先开启练习模式（`.prac`）。三个模块为独立开关（toggle），再次执行同一命令即关闭，互不影响、独立记忆状态，无总开关；开启时显示对应 HUD 面板，全部关闭后隐藏。
>
> - **急停评估**：判定同轴移动键（A/D、W/S）切换时序，输出「完美/优秀/偏早/偏晚」与平均差（tick）、成功率、标准差、整体趋势。
> - **开枪稳定**：开火瞬间采样水平速度并与当前武器精度阈值比较，输出速度误差与标签（稳定/蹲射/微动/跑打等）及近期稳定占比。
> - **空中同步**：移植 cs2kz 跳跃统计的同步算法——空中每 tick 若有移动输入且水平速度实际增益则记为同步 tick；无输入（dead air）、同轴双键同按（overlap）与无效角度 tick 计入分母但不计同步。显示当前值、均值与最佳值。
>
> `.hudreset` 仅清空统计，开关状态保留。
>
> **HUD 面板需要客户端安装 VPK 资源**：未安装 `prac_hud.vpk` 时判定与统计仍在服务器侧正常工作，玩家只是看不到面板（部署方式见[安装文档](安装.md)的「练习 HUD 资源」小节）。

#### 移动面板位置（.hudmove）

`.hudmove` 进入面板移动编辑模式，将面板摆放到屏幕任意九宫格位置：

1. 执行 `.hudmove`：服务器释放你的鼠标指针（此时无法转视角/开枪）。
2. 点击要移动的面板：面板高亮并显示 3×3 透明网格。
3. 点击网格中的目标位置：面板立即移动到对应九宫格位置（左上/上中/右上/…/右下），并自动退出编辑模式；**目标位置已被其他面板占用时两者交换**（被占面板移到本面板原位置），面板永不重叠。
4. 退出方式：放置完成 / 按 **Tab** 键 / 再次执行 `.hudmove`——均会收回鼠标恢复视角操作。

> - 面板位置为**个人偏好，仅本次会话内有效**：换图或重连后回到默认位置（屏幕左列上/中/下排列）。
> - 编辑模式中关闭任意面板（如 `.shot`）会直接退出编辑模式。
> - 点击面板需要客户端安装 `prac_hud.vpk`（按钮交互由 VXML 提供）。

#### 面板读数

**急停评估**

| 读数         | 含义                                                                                                                                                                                           |
| ---          | ---                                                                                                                                                                                            |
| 判定标签     | 同轴双键（A/D、W/S）切换时机：**完美** = 同 tick 内完成切换；**优秀** = 差 ≤1 tick；**偏早**（差为负）= 对侧键先按下；**偏晚**（差为正）= 先松键再按对侧。判定色：完美绿 / 优秀黄 / 偏早偏晚红 |
| `±N tick`    | 本次切换的实际差值（tick 数，1 tick ≈ 15.6 ms@64tick / 7.8 ms@128tick），`0` 为最佳                                                                                                            |
| 平均 ±X tick | 全部记录的平均偏差，越接近 0 越好                                                                                                                                                              |
| 成功 Y%      | 达到「优秀」（差 ≤1 tick）的记录占比                                                                                                                                                           |
| 标准 Z       | 记录的离散程度（标准差），越小越稳定                                                                                                                                                           |
| 趋势         | 平均差 `< -1` tick 显示「整体偏早」，`> 1` tick 显示「整体偏晚」，其余显示「正常」                                                                                                             |

**开枪稳定**

| 读数          | 含义                                                                                                                                                                          |
| ---           | ---                                                                                                                                                                           |
| 标签          | 开火瞬间的移动状态：**稳定** = 速度比 ≤1（在该武器移动精度内）；**微动** = ≤1.5；**低速摆动** / **起步低速** = 移动键刚按下或低速漂移；**跑打** = >1.5；**蹲射** = 下蹲中开枪 |
| `0.75` 等数值 | 速度比 = 开火瞬间水平速度 ÷ 当前武器精度阈值，`≤ 1.00` 表示在精度内，越小越准                                                                                                 |
| 稳定 Y%       | 近期记录中速度比 ≤1 的占比                                                                                                                                                    |

> 各武器的精度阈值内置于插件（见[配置文档](配置.md)的 `hud.cfg` 小节），未收录武器使用默认值。

**空中同步**

| 读数       | 含义                                                                                                                                 |
| ---        | ---                                                                                                                                  |
| 第一行数值 | 当前空中段的同步率（%）＝ 有移动输入且水平速度增益的 tick 数 ÷ 全部空中 tick 数（dead air / overlap / 无效角度均计入分母但不算同步） |
| 第二行数值 | 近期空中段的平均同步率                                                                                                               |
| 第三行数值 | 历史最佳同步率                                                                                                                       |

### 压枪轨迹

| 命令      | 别名 | 功能                                       |
| --------- | --   | ------------------------------------------ |
| `.recoil` | —    | 开关压枪鼠标轨迹（世界空间绿色 beam 折线） |

> **原理**：开火时在视线前方锚定虚拟画板，逐 tick 将鼠标移动（视角差分）绘制为世界空间绿色 beam 折线——压枪下拉时轨迹向下延伸，左右修正式横向偏折。
>
> **轨迹生命周期**：换弹 / 切枪 / 停顿超过重置间隔后自动清除旧轨迹并重新开始；松开开火键立即停止记录。
>
> **无 HUD 面板**：不依赖 VPK 资源，仅在世界空间绘制。轨迹参数（缩放 / 画板距离 / 段上限 / 重置间隔）见[配置文档](配置.md)的 `hud.cfg` 小节。
